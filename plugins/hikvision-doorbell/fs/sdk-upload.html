Hikvision SDK for call push

Push mode lets the door station tell Scrypted about a ring the moment the button is pressed, instead of Scrypted asking it every second. It needs Hikvision's Device Network SDK, which Hikvision does not allow plugins to include, so download it yourself and upload the zip here.

  1. Download the Device Network SDK for this server's processor:
    • arm64 (Raspberry Pi and most ARM boxes): the "ArmLinux64" package on Hikvision's open platform. The download asks for a Hikvision open platform account, which signs in with a phone number.
    • x64 (Intel or AMD): "Device Network SDK_Linux64" on Hikvision HiTools.
  2. Upload the zip exactly as downloaded. Only its Linux library folder is kept.
  3. In the doorbell's settings, set Call Detection to "Push (Hikvision SDK)".
